## Machine-readable metadata

The repository root contains a [`CITATION.cff`](../../CITATION.cff) file
(Citation File Format 1.2.0). GitHub renders a "Cite this repository" widget
from it, and tools such as Zenodo consume it directly. Keep `CITATION.cff`,
this file, and `CHANGELOG.md` version-consistent on every release.
